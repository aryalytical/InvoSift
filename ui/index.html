About InvoSift

A private, local-first workflow for turning invoices into usable data.

INVOICE WORKSPACE

From document to decision-ready data.

InvoSift turns PDF and image invoices into searchable, reviewable records — with local AI processing.

01

Import

Choose or drag in a PDF, PNG or JPG invoice. The file is checked before processing.

02

Read

Document rendering and OCR identify text, tables and important invoice regions.

03

Extract

The local AI model structures supplier, customer, dates, totals, tax and line items.

04

Validate

Validation checks the extracted values and flags records that need a human review.

05

Organise

Save searchable invoice history, reopen details and inspect the original source document.

06

Export & ask

Export Excel, CSV, JSON or text, or ask questions about the selected invoice in chat.

Features

  • PDF, PNG and JPG invoice intake
  • Local OCR and AI-assisted field extraction
  • Invoice history, search and sorting
  • Source-document preview and field review
  • Excel, CSV, JSON and TXT exports
  • Invoice-aware AI chat

Privacy & processing

Invoice files are processed by the local backend on this computer. OCR and extraction use local components and the Ollama model configured on this device. Extracted records and source files are stored in the app's local data directory. No cloud invoice-processing service is configured by this application.

Network access is used when you choose to install Ollama or download a model. Once installed, inference runs through the local Ollama service.
